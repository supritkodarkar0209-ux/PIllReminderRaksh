# 💊 Pill Reminder (Raksh)

A TypeScript-based medication reminder application that helps users manage their daily medication schedule, never miss a dose, and track their health.

---

## 🎯 Features

- **Smart Reminders**: Get timely notifications for medication
- **Dose Tracking**: Keep track of all your medications and dosages
- **Schedule Management**: Create custom medication schedules
- **Refill Alerts**: Get reminded when it's time to refill prescriptions
- **Medical History**: Maintain a log of medication history
- **Multiple Profiles**: Manage medications for family members
- **Easy-to-Use Interface**: Simple and intuitive design

---

## 🛠️ Tech Stack

- **Language**: TypeScript
- **Type Safety**: Full TypeScript support for reliable code
- **Architecture**: Component-based and modular design
- **Styling**: Modern responsive UI
- **Mobile-Ready**: Works seamlessly on all devices

---

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/supritkodarkar0209-ux/PIllReminderRaksh.git
   cd PIllReminderRaksh
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Build the project**
   ```bash
   npm run build
   ```

4. **Start the application**
   ```bash
   npm start
   ```

5. **Open in browser**
   ```
   http://localhost:3000
   ```

## 💡 Usage

### Setting Up Medications
1. Open the app and navigate to "Add Medication"
2. Enter medication name, dosage, and frequency
3. Set reminder times
4. Save your medication profile

### Daily Reminders
- Receive push notifications at scheduled times
- Mark pills as taken in the app
- View your medication history

### Managing Refills
- Track refill dates
- Get reminder when refills are due
- Check refill status anytime
